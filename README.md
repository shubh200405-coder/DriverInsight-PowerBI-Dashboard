# 🚗 DriverInsight – Premium Used Car Market Analytics Dashboard

An interactive **Power BI** dashboard built to analyze the premium used car market using Business Intelligence techniques. The project transforms raw vehicle listing data into meaningful insights through interactive visualizations, dynamic filtering, and professional dashboard design.

---

# 📌 Project Overview

DriverInsight is a premium Business Intelligence solution developed in Microsoft Power BI to help users analyze the used car market efficiently. The dashboard provides detailed insights into vehicle pricing, technical specifications, ownership history, fuel types, transmission, geographical distribution, and brand performance.

The project combines data cleaning, transformation, DAX calculations, data modeling, and interactive dashboard design to support data-driven decision-making.

---

# 🎯 Business Problem

The used car market consists of thousands of listings with varying prices, specifications, ownership records, and regional differences. Comparing vehicles manually is inefficient and often results in poor purchasing or business decisions.

DriverInsight solves this challenge by providing a centralized interactive dashboard that enables users to explore, compare, and analyze vehicles with ease.

---

# 🎯 Project Objectives

- Analyze premium used car market trends.
- Compare vehicle prices across brands.
- Explore technical specifications and performance metrics.
- Study ownership, fuel type, and transmission patterns.
- Analyze geographical distribution of vehicle listings.
- Create dynamic vehicle profiles for detailed exploration.
- Build an executive dashboard for business intelligence reporting.
